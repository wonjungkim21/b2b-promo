# 프레시밀 포인트 이벤트 응모(freshmeal-point-event) 와이어프레임

버전: v1.1 (2026-08-13)
기반 문서: `docs/4-PRD.md` v1.2, `docs/5-user-scenario.md` v1.0, `docs/7-arch-diagram.md` v1.1

## 1. 개요

- 목적: PRD 4.1 화면 범위를 텍스트 기반 ASCII 레이아웃으로 표현하여, 이후 상세 화면 정의서/구현 작업의 시각적 출발점을 제공한다.
- 표현 수준: 실제 색상/폰트/픽셀 단위 디자인이 아니라, 각 화면의 영역 배치와 요소 순서만 나타낸다 (오버엔지니어링 금지).
- 반응형 원칙(PRD 8장): 반응형 웹 UI를 필수 적용하되, 사용자 화면은 모바일을 기준으로 설계하고 넓은 화면(데스크탑)에서는 콘텐츠 폭을 제한하거나 목록을 다열로 확장하는 식으로 대응한다. 관리자 화면은 데스크탑 표/리스트 레이아웃을 기준으로 설계하고, 좁은 화면(태블릿 이하)에서는 표를 카드형으로 접어(stack) 대응한다. 별도 네이티브 앱은 없으며 하나의 웹 화면이 CSS로만 반응한다. 접근성(a11y)은 범위 제외.
- 브레이크포인트(단순화): 모바일 ~767px / 데스크탑 768px 이상, 2단계만 사용한다(태블릿 별도 단계 없음).

## 2. 사용자 화면 (모바일 우선)

### 2.1 회원가입 (UC-0)

```
+-----------------------------+
|      freshmeal 회원가입     |
+-----------------------------+
| 이름       [____________]   |
| 로그인ID   [____________]   |
| 비밀번호   [____________]   |
| 비밀번호확인[____________]   |
|                             |
| [ 오류 메시지 영역 (있을 때) ]|
|                             |
|      [   가입하기   ]       |
|                             |
| 이미 계정이 있나요? 로그인   |
+-----------------------------+
```
- 필수 입력값(name, loginId, 비밀번호)을 세로로 배치. 가입 성공 시 로그인 화면으로 이동(UC-0 3.1-1).
- loginId 중복 시 오류 메시지 영역에 안내 표시, 계정 미생성(UC-0 3.1-2).

### 2.2 로그인 (UC-1)

```
+-----------------------------+
|        freshmeal 로그인     |
+-----------------------------+
| 로그인ID   [____________]   |
| 비밀번호   [____________]   |
|                             |
| [ 인증 실패 오류 메시지 ]    |
|                             |
|      [   로그인   ]         |
|                             |
| 계정이 없나요? 회원가입      |
+-----------------------------+
```
- 로그인 성공 시 Access/Refresh Token 발급 후 role에 따라 이벤트 목록(사용자) 또는 관리자 이벤트 목록(관리자)으로 이동(UC-1 3.2-1).
- 인증 실패 시 오류 메시지만 표시, 토큰 미발급(UC-1 3.2-2).

### 2.3 이벤트 목록 (UC-2, UC-4)

SVG 샘플(모바일 뷰): [`assets/8-wireframe-event-list.svg`](assets/8-wireframe-event-list.svg)

```
+-----------------------------+
| freshmeal        [내 포인트]| <- PointBalanceBadge (UC-4)
|                  1,500 P    |
+-----------------------------+
| [진행중] 여름 특가 이벤트    | <- EventCard + StatusBadge
| 07.01 ~ 08.31          >    |
+-----------------------------+
| [예정]   가을 신메뉴 이벤트  |
| 09.01 ~ 09.30          >    |
+-----------------------------+
| [진행중] 재구매 포인트 2배   |
| 08.01 ~ 08.20          >    |
+-----------------------------+
|                             |
| [ 내 응모 내역 ]  (하단 메뉴)|
+-----------------------------+
```
- 상단 공통 영역에 보유 포인트 배지 상시 노출(UC-4 3.5-1). 카드 목록은 status가 `진행중`/`예정`인 이벤트만 노출, `종료`는 제외(UC-2 3.3-1).
- 카드 클릭 시 이벤트 상세로 이동, 하단에 내 응모 내역 진입 메뉴 배치.

**데스크탑 뷰(768px 이상)**: 동일한 EventCard를 3열 그리드로 배치하고, "내 응모 내역" 진입 메뉴는 하단 대신 상단 우측 내비게이션으로 이동한다. 콘텐츠 최대 폭을 제한해 카드가 과도하게 늘어나지 않게 한다.

```
+-----------------------------------------------------------------+
| freshmeal                [내 포인트 1,500 P]  [내 응모 내역]   |
+-----------------------------------------------------------------+
| [진행중] 여름 특가       | [예정] 가을 신메뉴    | [진행중] 재구매|
| 07.01~08.31         >   | 09.01~09.30       >  | 08.01~08.20  >|
+-----------------------------------------------------------------+
```

### 2.4 이벤트 상세 — 정상 (UC-3, UC-4, UC-5, UC-6, UC-7)

```
+-----------------------------+
| < 뒤로       [내 포인트]    |
|              1,500 P        |
+-----------------------------+
| [ 이벤트 이미지 (있는 경우) ]|
|                             |
| 여름 특가 이벤트   [진행중] | <- 이벤트명 + StatusBadge (UC-3)
| 기간: 07.01 ~ 08.31          |
| 경품/혜택: 스타벅스 기프티콘  |
+-----------------------------+
| 최대 응모 가능 횟수: 1회     | <- pointBalance÷1000 (UC-5)
+-----------------------------+
| 응모 횟수  [ - ] [ 1 ] [ + ] | <- 1이상 정수 입력/증감 (UC-6)
|                             |
| 사용 예정 포인트: 1,000 P    | <- 횟수×1,000 미리보기
| 응모 후 잔여 포인트: 500 P   | <- pointBalance - 사용예정
+-----------------------------+
|      [   응모 확정   ]      | <- UC-7, 활성 상태
+-----------------------------+
```
- 상세 정보(이미지/기간/혜택/상태) → 최대 응모 가능 횟수 → 횟수 선택/미리보기 → 응모 확정 버튼 순으로 세로 배치해 한 화면 안에서 UC-5→UC-6→UC-7 흐름을 그대로 따라가게 한다.
- 응모 확정 클릭 시 원자적 트랜잭션 처리 결과(갱신된 잔여 포인트, 누적 응모 횟수)를 같은 화면 상단 배지/영역에 갱신 표시(UC-7 3.8-1, 도메인 5.4/5.5/5.7).

**데스크탑 뷰(768px 이상)**: 세로로 쌓았던 "정보 영역"과 "응모 영역"을 좌우 2단으로 나눈다. 요소 구성과 흐름(UC-5→UC-6→UC-7)은 동일하고 배치만 좌/우로 바뀐다.

```
+-------------------------------+-----------------------------+
| < 뒤로          [내 포인트 1,500 P]                          |
+-------------------------------+-----------------------------+
| [ 이벤트 이미지 ]              | 최대 응모 가능 횟수: 1회      |
| 여름 특가 이벤트    [진행중]  |-------------------------------|
| 기간: 07.01 ~ 08.31            | 응모 횟수  [ - ] [ 1 ] [ + ]  |
| 경품/혜택: 스타벅스 기프티콘    | 사용 예정 포인트: 1,000 P     |
|                                | 응모 후 잔여 포인트: 500 P    |
|                                |     [   응모 확정   ]         |
+-------------------------------+-----------------------------+
```

### 2.5 이벤트 상세 — 예외: 포인트 부족/부족 임박 (도메인 5.2, UC-5 3.6-2)

```
+-----------------------------+
| < 뒤로       [내 포인트]    |
|                800 P        |
+-----------------------------+
| [ 이벤트 이미지 ]            |
| 여름 특가 이벤트   [진행중] |
| 기간: 07.01 ~ 08.31          |
+-----------------------------+
| 최대 응모 가능 횟수: 0회     | <- 800P < 1,000P → 0회
| ⚠ 포인트가 부족하여          |
|   응모할 수 없습니다.         |
+-----------------------------+
| 응모 횟수  [ - ] [ 0 ] [ + ] | <- 입력 비활성(disabled)
|                             |
| 사용 예정 포인트: -          |
| 응모 후 잔여 포인트: -       |
+-----------------------------+
|   [   응모 확정 (비활성)   ]| <- 회색/클릭 불가
+-----------------------------+
```
- 보유 포인트가 1,000 미만이면 최대 응모 가능 횟수 0회 + 안내 문구 표시, 횟수 입력란과 응모 확정 버튼을 비활성화해 응모 자체를 막는다(UC-5 3.6-2, 도메인 5.2).
- 횟수를 선택했더라도 확정 시점에 보유 포인트 < 선택 횟수×1,000이면 서버가 차감 없이 거부하고 동일한 부족 안내를 표시한다(UC-7 3.8-2).

### 2.6 내 응모 내역 (UC-8)

```
+-----------------------------+
| < 뒤로     내 응모 내역     |
+-----------------------------+
| 여름 특가 이벤트   [진행중] |
| 누적 응모: 2회               |
| 누적 사용 포인트: 2,000 P    |
| 최근 응모일: 08.10 14:22     |
+-----------------------------+
| 봄맞이 이벤트       [종료]  | <- 종료 이벤트도 포함(UC-8)
| 누적 응모: 1회               |
| 누적 사용 포인트: 1,000 P    |
| 최근 응모일: 05.02 09:10     |
+-----------------------------+
```
- 본인이 응모한 이벤트별 totalCount/totalPointsUsed/lastAppliedAt을 카드로 나열, status `종료` 이벤트도 그대로 노출(UC-8 3.9-1).

## 3. 관리자 화면 (데스크탑 우선)

### 3.1 관리자 이벤트 목록 (UC-9, UC-10, UC-11)

```
+---------------------------------------------------------------------+
| freshmeal 관리자                                    [ + 이벤트 등록 ]|
+---------------------------------------------------------------------+
| 이벤트명       | 기간              | 상태   | 응모현황 | 관리         |
|----------------|-------------------|--------|----------|--------------|
| 여름 특가 이벤트| 07.01 ~ 08.31     |[진행중]| 보기 >   | 수정 | 상태변경|
| 가을 신메뉴 이벤트|09.01 ~ 09.30    |[예정]  | 보기 >   | 수정 | 상태변경|
| 봄맞이 이벤트   | 03.01 ~ 05.01     |[종료]  | 보기 >   | 수정         |
+---------------------------------------------------------------------+
```
- 표 형태 목록에 상태 배지, 응모현황(UC-12) 진입 링크, 수정(UC-10), 상태변경(UC-11) 액션을 행별로 배치.
- 상단 "이벤트 등록" 버튼으로 등록 화면(UC-9) 진입. 상태변경은 `예정→진행중→종료`만 허용하고 역방향/건너뛰기는 UI에서 선택지 자체를 제공하지 않거나 서버 거부 메시지로 처리(도메인 3.2, 4.3-3/4.3-4).

**좁은 화면 뷰(767px 이하)**: 관리자 기능은 데스크탑 사용을 기본 전제로 하지만(PRD 8장), 반응형 원칙상 표는 행별 카드로 접어(stack) 최소한의 사용성을 보장한다.

```
+-----------------------------+
| freshmeal 관리자 [+ 등록]   |
+-----------------------------+
| 여름 특가 이벤트   [진행중] |
| 07.01 ~ 08.31                |
| 응모현황 | 수정 | 상태변경  |
+-----------------------------+
```

### 3.2 관리자 이벤트 등록/수정 (UC-9, UC-10)

```
+---------------------------------------------------------------------+
| < 목록으로              이벤트 등록 / 수정                          |
+---------------------------------------------------------------------+
| 이벤트명 *     [_____________________________]                     |
| 이미지(선택)   [ 파일 선택 ]                                        |
| 시작일시 *     [____________]   종료일시 * [____________]           |
| 상태 *         ( ) 예정  ( ) 진행중  ( ) 종료                        |
| 경품/혜택(선택)[_____________________________]                     |
|                                                                       |
| [ 유효성 오류 메시지 영역 (필수값 누락 / 종료<=시작 등) ]             |
|                                                                       |
|                                     [ 취소 ]   [ 저장 ]              |
+---------------------------------------------------------------------+
```
- 필수(*) 항목: 이벤트명/기간/상태. 이미지·경품/혜택은 선택 입력(UC-9 4.1-1, UC-10 4.2-1).
- 필수값 누락 또는 종료일시 ≤ 시작일시면 저장 거부하고 오류 메시지 표시, 등록/수정 화면 모두 동일 규칙 적용(UC-9 4.1-2, UC-10 4.2-2, 도메인 3.2).

### 3.3 관리자 이벤트별 응모 현황 (UC-12)

```
+---------------------------------------------------------------------+
| < 목록으로        여름 특가 이벤트 - 응모 현황                       |
+---------------------------------------------------------------------+
| 전체 응모 횟수(SUM totalCount) : 128 회                              |
| 참여 사용자 수(row count)      : 64 명                               |
+---------------------------------------------------------------------+
```
- 이벤트 목록에서 "보기" 클릭 시 진입, 전체 응모 횟수와 참여 사용자 수 2개 지표만 단순 표시(UC-12 4.4-1).
