# 프레시밀 포인트 이벤트 응모(freshmeal-point-event) UI 스타일 가이드

버전: v1.3 (2026-08-20)
기반 문서: `docs/8-wireframe.md` v1.4 (화면 레이아웃), `docs/6-project-principle.md` v1.4 (프론트엔드 디렉토리 구조)
참고 자료:
- 첨부된 스타벅스 앱 캡처 4종(홈, 리워드, 로그인, What's New 목록) — 레이아웃/컴포넌트 패턴의 참고 자료(브랜드 자산을 그대로 복제하지 않음).
- 프레시밀 자체 브랜드 자산(로고 아이콘 `frontend/public/logo.png`, 앱 캡처) — 실제 서비스 브랜드이므로 색상값은 로고 이미지에서 직접 추출한 실측값(`#416922`)을 사용한다.

## 1. 개요

- 목적: `docs/8-wireframe.md`가 정의한 화면 배치(ASCII)에 실제 색상·타이포그래피·컴포넌트 스타일을 입혀, FE-3(공용 컴포넌트 및 반응형 레이아웃) 이후 구현 작업의 시각적 기준을 제공한다.
- 범위: 색상 팔레트, 타이포그래피, 여백 스케일, 공통 컴포넌트(버튼/인풋/배지/카드/탭/진행바/하단 내비게이션) 스타일만 정의한다. 실제 컴포넌트 코드나 CSS 프레임워크 선택은 이 문서의 범위 밖이다(원칙 4번: 오버엔지니어링 금지, 지금 필요한 값만 정의).
- 톤앤매너: 따뜻한 뉴트럴 배경 위에 선명한 그린 포인트 컬러 하나로 강조하는 방식(캡처 공통 패턴). 회원 등급/포인트처럼 "성취감"을 주는 화면은 그라디언트 히어로 배경을, 로그인/목록처럼 기능 중심 화면은 흰 배경 + 미니멀한 라인 스타일을 사용한다.

## 2. 컬러 팔레트

| 토큰 | HEX | 용도 |
|---|---|---|
| `--color-primary` | `#416922` | 브랜드 그린(로고 배경색 실측값). 진행바 채움, 강조 텍스트(등급/포인트 수치), 주요 버튼 배경, 활성 탭 밑줄 |
| `--color-primary-dark` | `#2F4E19` | 버튼 눌림(active) 상태, 강조 텍스트의 어두운 변형 |
| `--color-primary-tint` | `#E7EEDD` | 초록 배지 배경, 연한 강조 영역 |
| `--color-background` | `#F9F6E5` | 페이지 기본 배경(따뜻한 크림톤 — 프레시밀 앱 캡처 배경 실측값), 로그인/회원가입 화면 배경 |
| `--color-text-primary` | `#1A1A1A` | 본문/제목 텍스트 |
| `--color-text-secondary` | `#767676` | 설명/캡션/비활성 텍스트, placeholder |
| `--color-border` | `#E5E5E1` | 인풋 밑줄, 리스트 구분선, 카드 테두리 |
| `--color-surface` | `#FFFFFF` | 카드/폼 등 콘텐츠 표면 배경 |
| `--color-surface-muted` | `#F5F5F3` | 정보성 배너/카드의 은은한 배경(진행바 트랙 포함) |
| `--color-track` | `#E0E0DC` | 진행바(progress bar)의 빈 트랙 |

- 강조는 항상 그린(`--color-primary`) 한 가지로 통일한다. 두 번째 강조색(골드 등)을 새로 만들지 않는다.
- 상태 배지(EventStatusBadge)는 팔레트를 재사용한다: `진행중` = `--color-primary` 배경 + 흰 텍스트, `예정` = `--color-primary-tint` 배경 + `--color-primary-dark` 텍스트, `종료` = `--color-border` 배경 + `--color-text-secondary` 텍스트(윤곽선만, 채도 낮게). `예정`을 `--color-surface-muted` 배경으로 두면 회색조+회색조라 가시성이 떨어져 연한 그린 tint로 대비를 확보한다.

## 3. 타이포그래피

- 본문 폰트(`--font-body`): 시스템 기본 산세리프(`-apple-system, "Apple SD Gothic Neo", "Pretendard", sans-serif`). 한글 본문·인풋·라벨 등 대부분의 텍스트에 사용한다.
- 브랜드 폰트(`--font-brand`): `Poppins`(Google Fonts, `frontend/index.html`에서 로드) — 로고 워드마크("FreshMeal")와 로그인/회원가입/관리자 헤더의 브랜드명 표기에만 한정해서 사용한다. Poppins는 한글 글리프가 없으므로 한글 텍스트에는 적용하지 않는다.
- 굵기 스케일은 3단계만 쓴다: `regular(400)` / `semibold(600)` / `bold(700)`. 화면마다 제목은 항상 `bold`, 본문은 `regular`, 강조 수치·라벨은 `semibold` 이상.

| 스타일 토큰 | 크기 | 굵기 | 용도 (캡처 근거) |
|---|---|---|---|
| `--text-display` | 28px / line-height 1.3 | bold | 히어로 카피("○○님과 함께 Dream Away") |
| `--text-title` | 24px / 1.3 | bold | 화면 제목("Starbucks® Rewards", "로그인", "What's New") |
| `--text-section` | 19px / 1.4 | bold | 섹션 헤더("추천 메뉴", "멤버십 등급", "등급별 혜택") |
| `--text-stat` | 40px / 1.0 | bold | 강조 수치(포인트 "9 / 30★") — 정수부는 `--color-text-primary`, 단위/보조 숫자는 `--color-primary` |
| `--text-body` | 16px / 1.5 | regular | 본문, 리스트 타이틀, 인풋 값 |
| `--text-caption` | 13px / 1.4 | regular | 날짜, 보조 설명, placeholder |
| `--text-label` | 14px / 1.4 | semibold | 탭 라벨, 하단 내비게이션 라벨, 배지 텍스트 |

## 4. 여백/레이아웃

- 기준 스페이싱 단위: `4px` 배수(`4/8/12/16/24/32`). 화면 좌우 기본 패딩은 모바일 `20px`, 데스크탑 콘텐츠는 최대 폭 `960px`로 중앙 정렬(`docs/6-project-principle.md`의 반응형 원칙과 동일한 767px/768px 2단계 브레이크포인트를 그대로 따른다).
- 카드/리스트 아이템 사이 간격은 `12px`, 섹션과 섹션 사이는 `32px`.
- 모서리 둥글기: 버튼/배지/프로모 배너 = `24px`(알약형에 가깝게), 원형 썸네일 = `50%`, 리스트 썸네일/일반 카드 = `12px`.

## 5. 컴포넌트 스타일

### 5.1 버튼 (Button)
- **주요 버튼(고정형)**: 화면 하단에 고정, 좌우 폭 100%, 모서리 각짐(둥글기 없음), 배경 `--color-primary`, 텍스트 흰색 `--text-body` bold. 예: 로그인 화면의 "로그인하기".
- **알약형 버튼(Pill)**: 텍스트만큼만 폭을 차지, 모서리 둥글기 `24px`. 배경이 채워진 형(`Delivers` 배송 버튼)과 테두리만 있는 아웃라인형(`별 히스토리`, 배경 흰색 + `--color-primary` 테두리/텍스트) 두 종류만 쓴다.
- 버튼은 이 두 종류로 통일하고, 화면마다 새 버튼 스타일을 만들지 않는다.

### 5.2 인풋 (Input)
- 박스형 테두리를 쓰지 않고 밑줄(underline)만 사용한다: 기본 `1px solid --color-border`, 포커스 시 `2px solid --color-primary`.
- placeholder는 `--color-text-secondary`, 좌우 패딩 없이 텍스트가 화면 좌측 여백에 바로 붙는 미니멀한 형태(로그인 화면의 "아이디"/"비밀번호" 참고).

### 5.3 보유 포인트 배지 (PointBalanceBadge)
- 알약형(pill) 배지: 배경 `--color-primary-tint`, 모서리 완전 둥글게(`24px`), 좌우 패딩 `16px` 상하 `10px`.
- "보유 포인트" 라벨은 `--text-caption` 크기(`--color-text-primary`), 뒤에 붙는 포인트 숫자(`N,NNN P`)는 `20px bold`, `--color-primary-dark`로 눈에 띄게 강조한다. 이벤트 목록/상세 화면 상단에 상시 노출(UC-4 3.5-1).
- `--color-track`(진행바 빈 트랙)은 현재 실제 화면에서 사용하는 곳이 없다(응모 가능 횟수 등은 텍스트로만 표시). 향후 진행률 시각화가 필요해지면 이 토큰을 재사용한다.

### 5.4 배지/칩 (Badge)
- 상태 칩(EventStatusBadge): 좌우 패딩 `8px`, 상하 `2px`, 모서리 둥글기 `6px`, `--text-label` 크기(14px, semibold), 배경색은 2.의 상태별 규칙을 따른다.

### 5.5 탭 (Tab)
- **밑줄 탭(Underline Tab)**: 여러 서브메뉴 전환(예: "My Rewards / How it works")에 사용. 활성 탭은 `--color-text-primary` bold + 하단 `2px --color-text-primary` 밑줄, 비활성은 `--color-text-secondary`, 밑줄 없음.
- **구분선 탭(Divider Tab)**: 단순 필터 전환(예: "Welcome ¦ Green ¦ Gold")에 사용. 활성 항목만 `--color-primary` bold, 비활성은 `--color-text-secondary`, 항목 사이는 얇은 세로선(`|`)으로 구분.

### 5.6 리스트 아이템 (List Row) — EventCard, MyApplicationsPage 카드에 재사용
- 카드 컨테이너: 배경 `--color-surface-muted`, 테두리 `1px --color-border`, 모서리 둥글기 `12px`, 내부 패딩 `16px`, 내부 요소 간 세로 간격 `8px`.
- 카드 안에서 상태 배지(5.4) → 제목 → 기간/보조정보 순으로 배치한다. 제목은 `16px bold`(`--color-text-primary`)로 가장 강조하고, 기간/보조정보는 `14px semibold`(`--color-text-secondary`)로 제목과 명확히 위계를 구분한다(제목·기간이 동일한 굵기/크기였을 때 가독성이 떨어져 굵기 차등을 뒀다).
- 아이템 사이는 이 카드 형태로 통일하고(그리드/리스트 모두 동일), 화면 내에서 구분선 스타일과 혼용하지 않는다.

### 5.7 로그인/회원가입 브랜드 영역
- 화면 배경 전체를 `--color-background`(크림톤)로 채우고, 그 위에 최대 폭 360px의 흰 카드(`--color-surface`)를 화면 정중앙(수직·수평)에 배치한다.
- 카드 상단에는 로고 아이콘(`frontend/public/logo.png`) + 브랜드 워드마크("FreshMeal", `--font-brand`, `--color-primary`)를 세로로 배치한다(`.brand-logo`).

### 5.8 공통 상단 바 (AppHeader)
- 로그인/회원가입을 제외한 모든 인증된 화면(모바일·데스크탑 동일)의 최상단에 고정 노출한다. 배경 `--color-surface`, 하단 `1px --color-border` 구분선, 좌우 패딩 `20px`.
- 좌측: 로고 아이콘(28px, 모서리 `8px`) + "FreshMeal" 워드마크(`--font-brand`, 18px bold, `--color-primary`). 클릭 시 role별 홈(사용자 → 이벤트 목록, 관리자 → 관리자 목록)으로 이동.
- 우측: 일반 사용자에게만 "내 응모 내역" 아이콘 노출(관리자에게는 노출하지 않음 — 관리자 전용 응모 현황은 관리자 목록에서 개별 이벤트 단위로 접근).
- 원래 계획했던 하단 고정 내비게이션(아이콘+라벨, 데스크탑에서 상단 전환)은 채택하지 않고, 이 상단 바 하나로 모바일·데스크탑을 통일했다(반응형 분기 로직 자체가 필요 없어져 더 단순하다).

### 5.9 보조 내비게이션 바 (TopNav)
- AppHeader 바로 아래, 화면별로 배치. 좌측 "← 뒤로" 버튼(13px, 테두리 없는 텍스트 버튼), 우측 "로그아웃" 버튼(13px, `--color-text-secondary`).
- 뒤로가기는 브라우저 히스토리(-1)가 아니라 화면마다 고정된 목적지로 이동한다: 이벤트 상세·내 응모 내역 → 이벤트 목록(`/`), 관리자 등록·수정·응모현황 → 관리자 목록(`/admin`). 브라우저 뒤로가기에 의존하면 진입 경로에 따라 도착지가 달라져 예측이 어렵기 때문이다.
- 이벤트 목록·관리자 목록처럼 그 자체가 최종 목적지인 화면에는 뒤로가기 버튼을 렌더링하지 않고 로그아웃 버튼만 남긴다.

### 5.10 이벤트 상세 섹션 카드 (Event Detail Sections)
- 이벤트 상세 화면은 가독성을 위해 카드형 섹션 4개로 나눈다: (1) 제목/상태배지/기간 (2) 경품·혜택(있을 때만) (3) 응모 정보(최대 응모 가능 횟수·수량 조절·포인트 미리보기) (4) 응모 확정.
- 섹션 컨테이너: 배경 `--color-surface`, 테두리 `1px --color-border`, 모서리 둥글기 `12px`, 내부 패딩 `16px`, 섹션 간 세로 간격 `16px`.
- 응모 확정 버튼은 풀폭, 배경 `--color-primary`, 비활성 시 `--color-border` 배경 + `--color-text-secondary` 텍스트로 명확히 구분한다.
- 응모 확정 버튼 클릭 시 즉시 요청을 보내지 않고, "응모 후에는 취소할 수 없습니다. 응모하시겠습니까?" 확인창(브라우저 네이티브 `confirm`)을 먼저 띄운다. 별도 커스텀 모달 컴포넌트를 만들지 않고 네이티브 확인창으로 충분히 요구사항(응모 전 재확인 단계)을 충족한다.
