# B2B-promo 도메인 정의서

## 1. 개요/목적

식자재 유통 거래처(외식업체, 급식업체 등)가 진행 중인 프로모션 정보를 한곳에서 확인하고 참여 신청할 수 있도록 하는 B2B 프로모션 웹 애플리케이션의 도메인을 정의한다. 관리자는 프로모션을 등록·관리하고 거래처의 참여 반응을 확인한다. 본 문서는 교육용 바이브코딩 실습 MVP를 위한 것으로, 핵심 개념과 규칙만 간결하게 다룬다.

## 2. 핵심 액터

- **관리자**: 프로모션을 등록·수정·게시/종료하고, 참여 신청 현황을 확인한다.
- **거래처 담당자**: 자가 회원가입 후 로그인하여 프로모션을 조회하고 참여 신청/취소한다.

## 3. 핵심 도메인 엔티티 및 관계

### 3.1 사용자 계정 (User)
- 속성: 계정ID, 이메일, 비밀번호(해시), 역할(관리자/거래처담당자), 이름, 연락처
- 거래처 담당자 계정은 거래처(Company)와 1:1 또는 N:1로 연결됨 (한 거래처에 담당자 여러 명 가능)

### 3.2 거래처 (Company)
- 속성: 거래처ID, 거래처명, 담당자 연락처
- 회원가입 시 거래처 정보를 입력/선택하여 사용자 계정과 연결

### 3.3 프로모션 (Promotion)
- 속성: 프로모션ID, 제목, 설명, 유형(가격할인/사은품증정/신제품시식), 시작일, 종료일, 게임적용여부
- 상태: `초안` → `게시중` → `종료`
  - 관리자만 상태 전이 가능
  - 거래처 담당자에게는 `게시중` 상태(및 시작 전 예정 프로모션)만 노출

### 3.4 경품 (Prize)
- 게임적용 프로모션에 종속되는 하위 엔티티
- 속성: 경품ID, 프로모션ID, 경품명, 당첨 확률(가중치)
- 경품 재고 관리는 MVP 범위 밖 (수량 차감 없음, 상시 추첨 가능)

### 3.5 참여 신청 (Application)
- 속성: 신청ID, 프로모션ID, 거래처ID, 신청자(User)ID, 신청일시, 상태, 추첨결과(경품ID, nullable)
- 상태: `신청됨` → `취소됨` → `재신청됨` (재신청 시에도 동일 레코드 재사용, 상태만 전이)
- (프로모션, 거래처) 조합당 레코드는 유일 — 3.6절 비즈니스 규칙 참고
- 게임적용 프로모션의 경우 신청 시점에 서버가 경품을 1회 즉시 추첨하여 결과를 확정, 이후 불변

### 관계 요약
- Company 1 : N User
- Promotion 1 : N Prize (게임적용 프로모션에 한함)
- Promotion 1 : N Application, Company 1 : N Application
- (Promotion, Company) 조합은 Application 1건으로 유일

## 4. 유스케이스 목록

### 관리자
- 프로모션 등록 (유형 선택, 게임 적용 여부 및 경품 목록 등록)
- 프로모션 수정
- 프로모션 게시/종료 상태 변경
- 프로모션별 참여 신청 현황 조회 (신청자, 추첨 결과 포함)
- 마이페이지: 내 정보 조회/수정, 비밀번호 변경

### 거래처 담당자
- 회원가입 (거래처 정보 입력/선택 포함)
- 로그인
- 진행 중/예정 프로모션 목록 조회
- 프로모션 상세 조회
- 프로모션 참여 신청 (게임적용 시 서버 즉시 추첨 → 룰렛 애니메이션 → 결과 표시)
- 내 신청 목록 조회 (당첨 결과 포함)
- 신청 취소
- 취소한 신청 재신청
- 마이페이지: 내 정보 조회/수정, 비밀번호 변경

### 공통
- 로그인/로그아웃 (인증 후에만 기능 이용 가능)

## 5. 예외 케이스 및 비즈니스 규칙

- **신청 유일성**: (프로모션, 거래처) 조합당 참여 신청 레코드는 정확히 1건만 존재한다. 동일 거래처가 동일 프로모션에 중복 신청 레코드를 생성할 수 없다.
- **취소/재신청은 상태 전이**: 신청 취소 및 재신청은 새 레코드 생성이 아니라 기존 레코드의 상태를 전환하는 것으로 처리한다 (`신청됨` → `취소됨` → `재신청됨`).
- **추첨 1회 확정, 불변**: 게임적용 프로모션의 추첨은 최초 신청 시 1회만 수행되며, 이후 재추첨은 허용하지 않는다. 재신청 시에도 최초 추첨 결과를 그대로 유지한다 (결과 필드는 불변).
- 종료되었거나 아직 시작하지 않은 프로모션에는 신규 참여 신청이 불가하다.
- 게임적용이 아닌 프로모션은 추첨 결과 없이 신청 상태만 관리한다.

## 6. MVP 범위

### 포함
- 프로모션 등록/수정/게시/종료 관리 (관리자)
- 거래처 담당자 회원가입/로그인
- 프로모션 목록/상세 조회
- 참여 신청/취소/재신청
- 게임(룰렛) 적용 프로모션의 즉시 추첨 및 결과 확인
- 마이페이지 (내 정보 조회/수정, 비밀번호 변경) - 관리자/거래처 담당자 공통
- 반응형 UI (모바일/데스크탑 대응)

### 제외
- 실제 주문/결제/정산
- 재고 실시간 연동
- 승인 워크플로우
- 거래처 등급별 차등가
- 포인트 적립
- 검색 기능
- 경품 재고 관리
