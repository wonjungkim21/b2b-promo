# 비즈니스 관련 정보
 - 목표 사용자: 1000 명 이상의 일반 사용자가 가입하여 사용함
 - 비즈니스 목표: 3000개 이상의 일반 사용자가 이벤트 응모를 사용함
 
# 기술 제약사항
 - 플랫폼 우선순위: 웹 애플리케이션 개발, 모바일은 반응형 UI로만 고려함.
    *반응형 웹 UI는 반드시 적용
 - 인프라 제약 
   * 프론트엔드 : React19 , 전역상태관리(Zustand), TanstackQuery를 이용해 백엔드와 통신
   * 백엔드 :  node.js+express, pg 라이브러리
   * 데이터베이스 : postgresql 17
 
# 프로젝트 관리
 - 일정: 3일 내에 핵심 기능 완성
 - 팀 구성: 1인 개발
 - 예산: 1인 개발에 준하는 예산

# 사용자 경험
 - 사용자 페르소나: 주 사용자별 상세 시나리오는 생략
 - 접근성: 이 앱에서는 고려하지 않음
 - 모바일 우선: 반응형 UI 적용
