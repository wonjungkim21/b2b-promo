## 배포 중 발견 후 조치한 이슈

**[FIXED] `VITE_API_BASE_URL`에 `/api` 경로 누락 → 전체 API 호출 404**

- 최초 접속 시 로그인 요청이 `POST https://honghak-123-be.vercel.app/auth/login`(실제 경로는 `/api/auth/login`)으로 나가 404가 발생, 사이트 전체가 동작하지 않았음.
- 원인: Vercel 프론트엔드 프로젝트의 `VITE_API_BASE_URL` 환경변수에 `/api` 접미사가 빠져 있었음(Vite는 빌드 시점에 이 값을 정적으로 번들에 굽는다).
- 조치: 사용자가 Vercel 대시보드에서 `VITE_API_BASE_URL=https://honghak-123-be.vercel.app/api`로 수정 후 재배포 → 재확인 결과 정상.
